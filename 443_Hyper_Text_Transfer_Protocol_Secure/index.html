Hyper Text Transfer Protocol Secure (HTTPS)

Port: 443
Type: Application Layer

Description

HTTPS (Hypertext Transfer Protocol Secure) is an extension of the HTTP protocol for secure communication over a computer network. It provides authentication of the website and associated web server, and protects the privacy and integrity of the exchanged data.

Technical Details

  • Uses TLS/SSL encryption to secure HTTP communications
  • Operates on port 443 by default
  • Establishes encrypted connection through TLS handshake
  • Supports various cipher suites for encryption

Security Considerations

HTTPS provides encryption, data integrity, and authentication. However, it's only as secure as the underlying TLS implementation and certificate validation. Vulnerabilities in TLS or weak certificates can compromise security.

Potential Abuse Cases

HTTPS can be used to hide malicious communications from network monitoring tools. Certificate pinning bypass techniques and man-in-the-middle attacks with fake certificates are potential threats.

Detection Strategies

Monitor certificate information, SNI (Server Name Indication) values, and TLS handshake patterns. Deep packet inspection can reveal malicious content despite encryption.

Mitigation Techniques

Use strong cipher suites, properly validate certificates, implement HSTS (HTTP Strict Transport Security), and regularly update TLS implementations to patch vulnerabilities.
