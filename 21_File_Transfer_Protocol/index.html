File Transfer Protocol (FTP)

Port: 21
Type: Application Layer

Description

File Transfer Protocol (FTP) is a standard network protocol used for the transfer of computer files between a client and server on a computer network. FTP is built on a client-server model architecture and uses separate control and data connections between the client and the server.

Technical Details

  • Uses two separate channels: command channel (port 21) and data channel (various ports)
  • Supports both active and passive modes for data transfer
  • Plaintext protocol that transmits data and credentials in unencrypted form
  • Commonly used for uploading and downloading files to/from web servers

Security Considerations

FTP transmits usernames, passwords, and data in plaintext, making it vulnerable to interception. It lacks encryption for both authentication and data transfer, which makes it inappropriate for use over unsecured networks.

Potential Abuse Cases

Attackers can use FTP to exfiltrate sensitive data from compromised systems. FTP servers with weak authentication can be exploited for unauthorized file access. Anonymous FTP servers can be used for storing and sharing malicious files.

Detection Strategies

Monitor for FTP connections, especially those with anonymous login attempts. Look for large data transfers and connections from unusual IP addresses. Log authentication failures which might indicate brute force attempts.

Mitigation Techniques

Use FTPS (FTP over SSL) or SFTP (SSH File Transfer Protocol) instead of plain FTP. Implement strong authentication mechanisms, limit FTP access to trusted IPs, and use chroot directories to restrict file access.
