Simple Mail Transfer Protocol (SMTP)

Port: 25, 587, 465
Type: Application Layer

Description

SMTP (Simple Mail Transfer Protocol) is a TCP/IP protocol used for sending email messages between servers and from email clients to mail servers. It is the standard protocol for email transmission across the internet.

Technical Details

  • Uses TCP port 25 for traditional SMTP communication
  • Uses ports 587 (submission) and 465 (SMTPS) for secure email submission
  • Follows request-response model with 3-digit reply codes
  • Standard commands include HELO/EHLO, MAIL FROM, RCPT TO, DATA, QUIT

Security Considerations

Traditional SMTP transmits data in plaintext. Modern implementations use STARTTLS or SMTPS for encryption. Open relays can be exploited for spam distribution.

Potential Abuse Cases

SMTP can be exploited for spam distribution, phishing attacks, and email-based malware delivery. Open relays can be abused to send large volumes of unsolicited emails.

Detection Strategies

Monitor for unusual email volumes, connections to known malicious email servers, and suspicious email patterns. SPF, DKIM, and DMARC records can help verify legitimate senders.

Mitigation Techniques

Implement authentication mechanisms, use secure SMTP (STARTTLS/SMTPS), configure proper SPF/DKIM/DMARC records, and limit relay access to authorized users only.
