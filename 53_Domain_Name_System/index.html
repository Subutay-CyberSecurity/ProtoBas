Domain Name System (DNS)

Port: 53
Type: Application Layer

Description

The Domain Name System (DNS) is a hierarchical and decentralized naming system for computers, services, or other resources connected to the Internet or a private network. It translates more readily memorized domain names to the numerical IP addresses needed for locating and identifying computer services.

Technical Details

  • Uses UDP port 53 for most queries, TCP for zone transfers
  • Hierarchical structure with root, top-level, and second-level domains
  • Supports various record types (A, AAAA, MX, CNAME, TXT, etc.)
  • Uses recursive and iterative query resolution

Security Considerations

DNS traditionally operates without encryption or authentication, making it vulnerable to spoofing, cache poisoning, and other attacks. DNSSEC provides authentication and integrity protection.

Potential Abuse Cases

DNS can be used for data exfiltration, command and control channels, and as part of DNS tunneling attacks. DNS amplification attacks can be used for DDoS.

Detection Strategies

Monitor for unusual DNS query patterns, large response sizes, and queries to known malicious domains. DNS query logging can reveal suspicious activities.

Mitigation Techniques

Implement DNS filtering, use DNSSEC for authentication, monitor DNS traffic, and consider DNS over HTTPS (DoH) or DNS over TLS (DoT) for enhanced privacy.
