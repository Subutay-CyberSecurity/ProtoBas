Secure Shell (SSH)

Port: 22
Type: Application Layer

Description

SSH (Secure Shell) is a cryptographic network protocol for operating network services securely over an unsecured network. Its most notable applications are remote login and command-line execution, but it can also be used for tunneling, forwarding TCP ports, and X11 connections.

Technical Details

  • Uses public-key cryptography to authenticate the remote computer and user
  • Provides a secure channel over unsecured networks
  • Supports various authentication methods including password and key-based
  • Uses strong encryption algorithms like AES, ChaCha20, etc.

Security Considerations

SSH provides confidentiality and integrity of data. However, it's vulnerable to brute-force attacks if weak passwords are used. Key-based authentication is more secure than password-based authentication.

Potential Abuse Cases

SSH can be used for encrypted command and control channels, tunneling other protocols, and pivoting to internal networks. Misconfigured SSH servers can provide unauthorized access to systems.

Detection Strategies

Monitor for SSH connections from unusual sources, unusual amounts of data being transferred, and connections during non-business hours. Log failed authentication attempts which might indicate brute force attacks.

Mitigation Techniques

Use key-based authentication instead of passwords, implement fail2ban or similar tools to prevent brute forcing, limit SSH access to necessary IP addresses, use jump hosts for access control, and regularly update SSH software.
