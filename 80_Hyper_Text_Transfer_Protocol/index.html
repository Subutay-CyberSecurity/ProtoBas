Hyper Text Transfer Protocol (HTTP)

Port: 80
Type: Application Layer

Description

Hypertext Transfer Protocol (HTTP) is an application-layer protocol for transmitting hypermedia documents, such as HTML. It was designed for communication between web browsers and web servers, but it can also be used for other purposes.

Technical Details

  • Stateless protocol where each command is executed independently
  • Uses request-response model between client and server
  • Common methods include GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS
  • HTTP/1.1 introduced persistent connections and chunked encoding

Security Considerations

HTTP transmits data in plaintext, making it vulnerable to eavesdropping and man-in-the-middle attacks. HTTPS (HTTP over TLS) provides encryption and is recommended for sensitive data.

Potential Abuse Cases

HTTP can be used for command and control channels, data exfiltration, hosting malicious content, and as a cover for malware distribution. HTTP tunneling can be used to bypass network security controls.

Detection Strategies

Monitor for unusual HTTP traffic patterns, suspicious user-agent strings, large data transfers, and connections to known malicious domains. Content inspection can reveal malicious payloads.

Mitigation Techniques

Use HTTPS instead of HTTP for sensitive communications, implement web application firewalls, monitor HTTP traffic for malicious patterns, validate and sanitize all inputs, and keep web servers updated.
